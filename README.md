# AO-Tennis-2-Cheat-Engine-Table
Cheat Table para o AO Tennis 2

​Esta tabela permite editar diversos aspectos do modo carreira do jogo AO Tennis 2, incluindo atributos, habilidades, dinheiro e o nome do seu atleta.
​
Funcionalidades:

- ​Atributos: Força, reflexo, velocidade do saque, resistência e velocidade.
​- Habilidades: Todas as habilidades editáveis. 
- Finanças: Modificação da quantidade de dinheiro.

​Instruções de Uso:

​1. Abra o Cheat Engine e anexe-o ao processo do AO Tennis 2.
​2. Carregue a sua tabela e ative os scripts "AO Tennis 2 - Carreira Editor" e "MASTER".
​3. Entre no seu modo carreira.
4. ​Acesse a tela de atributos do seu atleta para carregar os dados.
